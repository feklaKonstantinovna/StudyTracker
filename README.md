# StudyFlow

Локальный трекер учёбы: расписание, блоки, задачи, шаблоны, цели, темы, календарь, аналитика, JSON-бэкап.

Данные дня — `localStorage` ключ `sfv3`. План — отдельно, ключ `sf_plan`. Старый бэкап без новых полей открывается.

## Free и Pro

**Free**
- Собрать день в этом браузере без логина
- Блоки, задачи, шаблоны, цели
- Список вчерашнего долга
- Дата экзамена и статус успею / впритык / не успею

**Pro — 199 ₽/мес** (списание не подключено)
- Автосбор мягкого дня из Anki-долга
- Раскладка оставшихся часов до экзамена по пустым дням
- 7 дней preview с первого нажатия этих кнопок

Облако и Telegram в этом срезе не продаём и на GitHub Pages не обещаем.

## Промокод

`STUDYFLOW-PRO` включает Pro на 30 дней. Экран «Тарифы» → «Активировать Pro».
