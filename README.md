# StudyFlow

Трекер учёбы: расписание дня, цели, темы, календарь, аналитика.

Данные Free живут в браузере (`localStorage`, ключ `sfv3`). План подписки — отдельно, ключ `sf_plan`. Старый JSON-бэкап без `plan` открывается как Free.

## Free и Pro

**Free**
- Локальный трекер без регистрации
- Дни, блоки, шаблоны, цели, темы, канбан
- Бэкап JSON и экспорт CSV
- Без облака и без Telegram

**Pro — 399 ₽/мес**
- Один аккаунт, облако + Telegram-напоминания
- Синхронизация через свой backend (`/api/data`, magic-link)
- Утреннее и вечернее сообщение в Telegram
- Кнопка «сохранить в облако»

Активация: промокод `STUDYFLOW-PRO` (30 дней) или поле `plan` / `proUntil` в `db.json`. Платёжного SDK нет.

## GitHub Pages

Работает без backend: расписание, блоки, задачи, шаблоны, цели, темы, аналитика, JSON-бэкап.
Облако и Telegram на Pages выключены.
